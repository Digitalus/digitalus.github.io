My first open source contribution was a documentation fix. It was small, and that was the point.

Here's what helped:

- **Read the contributing guide first.** It told me how to set up the project and how to name branches.
- **Ask before building.** I opened an issue to confirm the fix was wanted.
- **Keep the pull request small.** Reviewers can merge a focused change quickly.
- **Respond to feedback kindly.** Maintainers are often volunteers with limited time.

Getting that first merge made me much more confident about contributing again.
