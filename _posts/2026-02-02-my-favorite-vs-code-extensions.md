I try to keep my editor lean. These are the extensions I use every day:

- **Prettier** formats code on save, so I never argue about spacing.
- **GitLens** shows who changed a line and why, which is useful when I return to old code.
- **Live Server** reloads the browser as I edit static pages.
- **Error Lens** puts error messages right next to the code that caused them.

Before installing anything new, I ask whether it saves time every week. If it doesn't, I skip it.
